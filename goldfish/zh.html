01 / 缘起

一起看见的世界

从一项私人色觉经历出发，追问我们如何确认彼此所见。

阅读第 01 页＋

创作起点 / 一次辨色探索

由自身色觉差异出发，我收集了同一设备上的六份辨色报告，并制作三分区色点图。

原创辨色示意 / 未经临床验证 / Machado 2009

项目 / 色彩叙事解谜游戏

玩家从生活中吸取颜色，填进画里，再在旁人的评价中擦去、修改。画家依然认得那些颜色，却开始怀疑自己的判断。

思想实验 / 倒置光谱

两个人可以用同一个词指认蓝色，心里却各自感受到不同的颜色。即使用同一套颜色词，我们也无法直接交换各自的观看经验。《金鱼》把这段距离转化为作画、评价与修改之间的张力。

设计问题

如果换成别人喜欢的颜色，就能得到更多赞赏，我们离被理解更近了吗？

02 / 日常

先让生活，充满颜色

照料、填色、拍照和作画让房间逐渐鲜活。

阅读第 02 页＋

01 / 填色，让日常发生

玩家先从生活物件吸取颜色，再将颜色填回场景。给花盆填入蓝色，男主便走过去浇水。幼苗长大、鱼缸有了水，新的物件状态与颜色逐步出现。房间也从稀疏灰淡，变得丰富而鲜活。

02 / 先成为一个有生活的人

浇花、养鱼、阅读、听歌、休息和打电话，把画家放回具体的日常里。玩家亲手照料物件，也保留与亲近之人的联系。色彩因此有了各自的来处，画里的每一笔都连着刚刚经历过的生活。

03 / 把每天的观察，变成一幅画

每天，玩家选择房间里的一个对象拍照，再到电脑取色与作画。发布作品、收到评论，为一天收尾。起初，这像一个清新的填色游戏：玩家记录生活，也自然相信男主看见的就是世界原本的样子。

03 / 压力

世界渐渐变小

擦除推进角色，评论逐渐改变他判断颜色的依据。

阅读第 03 页＋

第二至三章 / 从擦除到自我怀疑

第二章，玩家持续擦去画面，男主才会继续前进。第一章亲手照料过的颜色，如今成为必须舍弃的东西。擦除把继续前进与失去生活绑在一起。

回到电脑，评论说画面孤独、色调太冷。玩家记得自己照料出的鲜活生活，却开始怀疑，是否用错了颜色。

从此，每次取色都多了一层迟疑。玩家结合评论、场景与行动结果推测颜色的对应，再通过填色验证自己的判断。

第四章 / 突然进入第一人称

为世界填色，颜色却逐渐失控。第四章完成后，混乱城市突然允许转动视角，玩家从电脑画面进入第一人称。

浇花、休息和亲密联系退出日常。一天只剩醒来、作画、发布、等回应。昨天为好评作出的修改，成了今天的生活。

男主依然分得清蓝与绿。改变的是落笔的依据。他越来越习惯先想别人会如何评价，再决定自己该用哪一种颜色。

04 / 视角

最后一条金鱼

海岸被一道纸缝分开，同一幅终画在两人眼里呈现出不同颜色。

阅读第 04 页＋

红鱼 / 诞生、留下、改色

红鱼在照料中出现，在擦除后留下。最后，男主给它换了颜色。四周先是沉默，随后掌声响起。

熟悉的规则

终局方案撤去操作提示。每填一笔，男主便走下一级台阶。第二章以擦除换取前进，而此时，他靠填色继续下行。

他完成了一幅自己觉得无比难看的画，却听到了掌声。

换到她的视角

男主的色彩感知与现实相同，玩家因此把他的所见当成世界的标准。换到女主的视角才发现，别人所见的颜色不同。同一幅终画在她眼里，正是男主曾经认为最美的样子。

但他们永远无法知道彼此所见。

05 / 制作与玩法

场景制作与玩法

从三维底图到场景变体，从直觉填色到颜色推理。

阅读第 05 页＋

01 / 建模固定空间

布局与机位先被确定， 让后续图像沿用同一空间。

三维底图确定体积与光影，定向生图生成不同场景状态。 与二维动漫角色叠合，形成现实与动漫的观看落差。

第四章 / 填完后，进入画中

城市全部由三维建模完成。玩家为世界填色，但颜色此时已失控，最终形成混乱城市。填色完成后，视角突然可以转动，玩家从电脑画面进入第一人称。

三种工具，多层规则

取色 / 从环境中收集颜色

填色 / 向目标物件应用颜色

擦除 / 移除画面，推进角色

01 / 填色触发动作

给花盆填入蓝色，男主会走到花盆边浇水。

02 / 颜色选择去向

给出门目标填入不同颜色，就会进入不同场景。玩家通过填色选择接下来的去向。

03 / 从直觉填色，到颜色推理

观察场景、行动结果与评价，推测世界颜色与现实颜色的对应，再用填色验证。玩法由前期的直觉填色，逐渐转向解谜。

观察线索 → 推测对应 → 填色验证
