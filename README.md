# World Atlas

An interactive 3D portfolio by Wang Congrui.

[Open the public portfolio](https://discelysium.github.io/world-atlas/) · [Other Works](https://discelysium.github.io/world-atlas/other-works/)

One continuous world: OBLIVION, TennisAtom, SPACE, FLOW, Goldfish, Liar’s Mask and a photo atelier. Scroll to unfold the drafting sheet and explore the projects. Chinese and English, mobile framing and reduced-motion support are included.

The site is static and is served from the main branch by GitHub Pages. The `.nojekyll` file preserves all JavaScript and model asset directories.
